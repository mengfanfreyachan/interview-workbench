# 常见问题与排障

## 页面打不开

确认终端中的开发服务仍在运行。

```bash
npm run dev
```

默认地址是 [http://localhost:4173](http://localhost:4173)。如果端口已经被占用，Vite 会在终端显示新的本机地址，请打开实际显示的地址。

## 换端口后看不到原来的资料

浏览器会按网站地址隔离 `localStorage`。`localhost:4173` 和 `localhost:4174` 属于两个不同的数据空间。

回到旧地址导出 JSON，再在新地址点击“导入备份”。如果旧地址已经无法启动，可以重新指定原端口运行开发服务。

## DeepSeek 显示未配置

可以在“模拟作答”区域临时填写个人 Key，也可以在项目根目录创建 `.env.local`。

```dotenv
DEEPSEEK_API_KEY=your_private_key
DEEPSEEK_INTERVIEW_MODEL=deepseek-v4-pro
```

环境变量变更后需要重启 `npm run dev`。页面临时填写的 Key 不需要重启，但停止服务后会失效。

静态网页部署没有本机服务端桥接，因此 DeepSeek 配置入口和相关按钮不会工作。

## 小红书搜索提示登录或受限

先在普通 Chrome 中手动打开小红书搜索页，确认已经登录，并完成页面要求的验证。`opencli doctor` 和 `whoami` 正常，只能说明 OpenCLI 与登录会话存在，不能保证平台搜索页没有触发单独的登录墙、验证码或频率限制。

不要连续重试，也不要重装 Python。当前采集由 Node.js 版 OpenCLI 和 Chrome 扩展完成。等待一段时间后只重试一次，仍然受限时改用手动粘贴或文件导入。

工作台不会绕过登录、验证码或平台风控。

## 正文已读取，但没有识别到真题

这表示采集桥接已经取得可读正文或摘要，但保守解析器没有找到足够明确的题目片段。它不表示来源中一定没有面试问题。

如果来源卡片出现“重新识别真题”，先点击该按钮。系统会优先用已保存摘要重新提取；只有摘要不足、来源符合本机重读条件时，才重新读取有限数量的原文。也可以打开来源，把相关段落手动粘贴到面经输入框。

## 两个标签页显示的题目数不同

每个标签页有自己的页面状态。另一个标签页写入或清空数据后，当前页会提示有新数据，不会直接覆盖正在编辑的内容。

完成当前编辑后点击“加载最新数据”。如果没有看到提示，可以刷新较旧的标签页。

## 简历文件无法解析

支持 `.txt`、`.md`、现代 `.docx` 和带可复制文本层的 `.pdf`。扫描版、图片型、加密 PDF 和旧版 `.doc` 暂不支持。

旧版 `.doc` 可以在 Word 中另存为 `.docx`。扫描版 PDF 需要先在其他工具中完成 OCR，再把文字粘贴到工作台。单个文件不能超过 15 MB，解析后的正文不能超过 30,000 字。

## 导入备份失败

导入文件必须是工作台导出的 JSON，或能够迁移的 V1 到 V6 旧备份。系统会先在内存中验证和预览，失败不会覆盖现有浏览器数据。

不要手工删改 `schemaVersion`、岗位标识或来源引用。若文件来自旧环境，先保留原文件，再尝试从旧页面重新导出一次。
