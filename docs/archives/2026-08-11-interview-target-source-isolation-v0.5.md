# 面试工作台跨岗位面经隔离修复 V0.5

## 根因

旧实现将不同公司和岗位的采集来源追加到同一个全局数组，展示与题库生成没有按岗位过滤，导致产品运营与法务题混合。

## 修复

- 来源绑定采集时的公司和岗位；
- 当前页面只展示当前岗位来源；
- 题库引擎只接受当前岗位来源，并再次拒绝其他岗位与未归类来源；
- 题库绑定生成时岗位，切换岗位后旧题库停止展示；
- 手动面经草稿按岗位分别保存；
- 采集开始时冻结目标，异步返回不会误归到后来修改的岗位。

## V1 到 V2 迁移

旧来源没有岗位字段，不能从标题可靠推断。系统保留这些来源但将其放入未归类隔离区，并清空可能已混合的旧题库；简历继续保留。当前岗位需要重新采集。

## 验证

- TypeScript 检查通过；
- 7 个测试文件共 38 项测试通过；
- 生产构建通过；
- 法务题库拒绝产品运营来源与旧版未归类来源的回归测试通过。
