# 面试工作台独立 MVP V0.1

## 解决的问题

把分散的目标岗位、外部面经与个人简历组织成一次可执行的单题训练。模块在 `interview-workbench/` 独立运行，不依赖“向前”当前简历分析工作台或独立投递台的运行时代码。

## 产品决策与流程

流程固定为：填写公司和岗位 → 手动导入面经或导入 Agent Reach 结果 → 粘贴或上传文本简历 → 生成简历深挖题与岗位 / 专业题 → 选择单题 → 语音或文字回答 → 查看结构化示例反馈。

题库生成与评分当前使用确定性本地规则，界面明确标记为“本地原型生成”和“示例反馈”。外部导入题保留标题、平台、URL、采集时间、摘录与导入方式；规则题不能伪装成外部真题。

## 数据、权限与隐私

- 数据保存在当前浏览器的 `xiangqian.interview-workbench.v1`。
- 支持 JSON 导出和完整清除。
- Agent Reach 只通过 JSON 边界导入结果，本页面不执行联网采集。
- 简历仅解析 `.txt` / `.md` 文本，不承诺解析 Word / PDF。
- 语音输入使用浏览器原生 Speech Recognition，失败时回退到文字。
- 不包含账号、云同步、模型调用、后端语音模型、录用概率或自动决策。

## 已完成

- 独立 Vite / React / TypeScript 工程和运行说明；
- 响应式、键盘可操作的单页流程；
- 两类题库、来源标识、单题练习和五维示例评分；
- Agent Reach JSON 导入校验；
- 本地恢复、导出和清空；
- 纯函数测试、类型检查与生产构建入口。

协调者以 `agent-reach.interview-experience.v1` 格式提供真实脱敏结果，先验证来源完整性和重复题归并，再决定是否接入模型 provider。正式共享归档的建议路径为 `docs/archives/2026-08-10-interview-workbench-mvp-v0.1.md`；本次为避免越出独立模块，只在本模块内保存归档。
