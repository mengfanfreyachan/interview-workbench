# 视觉层级与简历编辑体验 V0.8

## 模块目标

修正简历正文过大、辅助文字过小和桌面材料区三列失衡，让工作台在保持现有纸张绿视觉方向的同时更接近可长期使用的产品界面。

## 已确认行为

- 简历解析结果是可编辑底稿，不是只读演示。
- 输入框、长文本、按钮、标签和说明建立统一字号层级。
- 桌面采用左侧岗位与简历、右侧面经的两列布局。
- 中等宽度使用两列加面经整行；手机端保持单列。

## 主要参数

- 普通输入：13px。
- 简历正文：12.5px / 1.78。
- 面经正文：13px / 1.75。
- 通用按钮：12px。
- 桌面材料列宽约为 36% / 64%。

## 实页验证

- 桌面材料区卡片高度和留白更平衡。
- 390 × 844 窄屏无横向溢出。
- 手机首屏、简历正文、DeepSeek 状态和 Key 配置展开态正常。
- 浏览器控制台无错误或警告。

## 当前边界

- 未做超长真实简历和大量来源压力测试。
- 未引入截图基线或自动视觉回归工具。
