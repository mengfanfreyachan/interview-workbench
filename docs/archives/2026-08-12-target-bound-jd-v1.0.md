# 岗位 JD 录入与绑定 V1.0

## 模块目标

为面试工作台补齐 JD 原始材料，并把每份 JD 严格绑定到公司＋岗位 target key，为后续来源化组题和证据审阅提供可靠输入。

## 已完成

- “准备岗位与材料”新增岗位 JD 卡片，支持直接粘贴和导入 `.txt` / `.md`。
- JD 原文保存在当前浏览器，用户可以继续核对和编辑。
- `jdDrafts` 按 target key 保存；切换历史面经库时自动切换到该岗位的 JD。
- 输入 JD 后会创建或更新对应的“我的面经库”岗位档案，历史卡片显示“含 JD”。
- 工作台本地数据版本升级为 V4；导出与恢复包含 JD，V1—V3 旧数据可继续读取，升级后 JD 为空。
- 不完整或键值与 target 不一致的 JD 数据在恢复时被丢弃，避免跨岗位污染。
- 准备进度由五项调整为六项，JD 单独占一项。

## 边界

- 本模块只完成 JD 录入、岗位绑定、保存、导出和恢复。
- 当前本地题库生成和 DeepSeek 回答分析尚未读取 JD，页面明确说明当前阶段不会自动发送 JD。
- 下一模块将使用 `interview.evidence-review.v1` 改造题库与 DeepSeek 接口。

## 验证

- TypeScript 检查通过。
- 52 个自动测试通过，其中新增 V4 JD 保存、V3 升级和非法 JD 隔离测试。
- 本地页面成功渲染 JD 卡片，控制台无错误或警告。
- 桌面、中等屏幕和手机布局规则均已覆盖 JD 卡片。
