# GitHub 产品视觉展示

## 背景

公开 README 原有截图只覆盖首页局部，访问者难以快速理解从准备材料到证据审阅的完整产品流程。仓库还缺少适合链接分享的横版预览图。

## 本次调整

- 新增一张 1600 × 900 的 README 主视觉，概括材料、题库、审阅和追问四个阶段。
- 新增四张真实桌面端流程截图，分别展示岗位材料、来源化题库、证据审阅和有界追问。
- 新增短动图，按实际操作顺序串联四个核心状态。
- 新增 1280 × 640、低于 1 MB 的 `social-preview.png`，供 GitHub 仓库 Social Preview 使用。
- README 首屏按产品定位、30 秒流程、四个核心步骤、安装与边界的顺序组织。

## 数据与真实性

所有画面均来自本机实际运行的工作台，没有重绘虚构界面。截图使用仓库内的虚构、脱敏样例；证据审阅画面使用临时脱敏演示状态生成，没有发起真实模型请求，也没有把临时代码提交到仓库。

## 未改变范围

本次仅调整公开展示资产和 README，没有修改产品代码、数据格式、模型协议、采集规则或运行架构。`v0.1.0` 版本号和首发标签保持不变。

GitHub Social Preview 图片已生成，但上传到仓库设置属于独立的公开页面变更，需要在发布资产后另行确认执行。
